News 4 U documentation¶

News 4 U is a Django application for readers, journalists, editors, and curated publishers. This reference describes its role permissions, approval services, and core data models.

For step-by-step workflows, see the user guide. Development setup and operations are covered in the development guide, and the available endpoints are listed in the API reference.

Build this documentation from the project root after installing docs/requirements.txt:

python -m sphinx -b html docs/source docs/generated
